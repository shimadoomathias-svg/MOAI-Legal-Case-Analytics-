Automated legal research

Automated legal research and outcome assessment

Submit one case. The system searches connected legal judgment sources and analyses the retrieved authorities; you do not need to build a case database first.

Nigeria research uses the free OpenLegal Nigeria API. United States research uses CourtListener when its API token is configured. Other jurisdictions will be enabled only when authorised legal-data access is available. Results are evidence-based research assessments, not legal advice or guaranteed outcomes.
Privacy warning: submitted facts are sent to the connected legal-source service as search terms and, when AI is enabled, to OpenRouter with selected public legal materials. United States searches are sent to CourtListener. Use anonymised facts only. Do not submit confidential, privileged or identifying client information.

1. OpenRouter — AI analysis

Required to generate the AI legal assessment. Keep the model on free routing.

  1. Open OpenRouter API keys and create a key.
  2. Open your Render Dashboard, select the MOAI Legal Case Analytics web service, then open Environment.
  3. Add OPENROUTER_API_KEY with your key as its value.
  4. Add OPENROUTER_MODEL with value openrouter/free.
  5. Save and deploy the changes.

2. CourtListener — United States cases

Optional. Nigeria research already works without a separate legal-source key.

  1. Create/sign in to a CourtListener account and request an API token through its account/API settings.
  2. In Render → this service → Environment, add COURTLISTENER_API_TOKEN with the token value.
  3. Save and deploy.

3. Database and application settings

DATABASE_URL is optional only if the service already has a persistent PostgreSQL database configured. For durable case records, use the existing PostgreSQL connection string. APP_PUBLIC_URL is optional and should be set to the deployed site URL.

Security: API keys are not entered into this public website or stored in its browser. Add them only in Render's private Environment settings. Never paste a key into a case, chat, GitHub file, or screenshot. After deployment, press “Check configuration” here.
